# Task Dashboard

Turn your moments and notes into structured tasks. Open the **Task Dashboard** with `Cmd+Shift+T` (Mac) or `Ctrl+Shift+T` (Windows/Linux), or press the `Tasks` item in the status bar.

- **Add a task** — type into the composer and press Enter; it lands in `tasks/inbox.md`
- **AI Extract** — let GitHub Copilot scan your Moments (or notes) for hidden action items, then add them with one click
- **Inline editing** — edit task text and due dates, toggle completion, or jump to the source file directly from the dashboard
